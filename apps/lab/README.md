# BandDrip Lab

A static, dependency-free browser simulator used for fast layout/safety iteration across Xiaomi band geometries.

It is intentionally **not called a Vela emulator**. Browser output is a layout model. Firmware-level evidence comes from the separate heavy Vela emulator workflow; physical hardware remains the final authority.

The GitHub Pages build copies `packages/devices/` into the site so device geometry/capability metadata has one source of truth.
