What is implemented

Mock source
Editable glucose, trend, age, delta and IOB plus deterministic edge-case fixtures.
Nightscout
Full tracking-link parsing, encrypted token storage, explicit connection status and fail-closed error handling.
xDrip
Local HTTP server at 127.0.0.1:17580 and xDrip broadcast-receiver path.
Background relay
START_STICKY foreground service, boot restart, notification, battery-optimization and Xiaomi power-management setup.
Wearable safety state
Band-side freshness timer, exact Xm ago, 10m stale boundary, line-through, delta and independent IOB freshness.
Band installation / transport
Bundled RPK + assisted Mi Fitness/Shizuku research exists, but Global Band 10 install and system.interconnect still require real hardware validation.

What is real vs simulated

Real: Android source adapters, protocol code, background service, RPK source, unit tests, APK build and Vela RPK build. Not real yet: this webpage is not Xiaomi firmware, and the raise-to-wake/watch-face integration is still experimental until a physical Band 10 proves it.
